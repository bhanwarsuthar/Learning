# GitHub Pages Documentation

This directory contains files for GitHub Pages deployment.

## Coverage Report

The coverage report is automatically generated by GitHub Actions and deployed here.

### Manual Setup

If you want to manually deploy coverage:

1. Generate coverage locally:
```bash
./generate_coverage_standalone.sh
```

2. Copy coverage files:
```bash
mkdir -p docs/coverage
cp -r coverage/html/* docs/coverage/
```

3. Commit and push:
```bash
git add docs/coverage/
git commit -m "Add coverage report"
git push
```

## GitHub Pages Configuration

1. Go to repository Settings > Pages
2. Source: Deploy from a branch
3. Branch: `gh-pages` (created by GitHub Actions)
4. Folder: `/ (root)`

The GitHub Actions workflow (`.github/workflows/coverage.yml`) will automatically:
- Run tests with coverage
- Generate HTML coverage report
- Deploy to GitHub Pages on each push to main/master
